Controls

Click the scene to walk or focus it and use the arrow keys. Press an arrow again to stop. Press the backtick key (`) to switch between original and enhanced graphics. With the game screen focused, press [ for the previous walking location or ] for the next.

Send a command like look in Transmissions. Type hint for the current room.

Use the game screen for choices and arcade sequences. Press F5 to save or F7 to restore.
